# 水下滑翔机 CSV 回放数字孪生原型设计

## 目标

第一期交付一个均衡版 Unity 数字孪生原型：使用本地 `2.csv` 历史下载数据驱动水下滑翔机三维回放，同时具备可展示的水下视觉、可分析的遥测仪表与轨迹回放、可扩展到实时通信和真实三维模型的工程结构。

交付物包括 Unity 工程和 Windows 可执行程序。

## 已确认环境

- 工作目录：`D:\Desktop\digital twin`
- Unity Editor：`2022.3.62f3c1`
- 可用软件：Unity Hub、MATLAB R2022b、Python/Anaconda、Node.js、Git、.NET 运行环境
- 当前数据文件：`D:\Desktop\digital twin\2.csv`
- `2.csv` 编码：GBK
- `2.csv` 规模：约 52 MB，236163 条数据记录，51 列

## 第一期范围

包含：

- 读取并解析 `2.csv`
- 由经纬度、深度、航向、纵摇、横摇驱动滑翔机模型
- 绘制实际轨迹和当前回放位置
- 显示关键遥测仪表
- 支持播放、暂停、倍速、进度条跳转
- 支持跟随视角、全局视角、自由视角
- 提供基础水下环境：指数雾、悬浮粒子、海底平面或简化地形、简化光束
- 生成程序化简化滑翔机模型，后续可替换为真实 `.fbx` 或 `.glb`
- 记录加载错误、报警事件和回放事件
- 打包 Windows 可执行程序

不包含：

- TCP、UDP、串口实时通信
- 6-DOF 自主物理解算
- PID、LQR、MPC 闭环控制
- 高精度水动力学模型
- 高保真真实滑翔机三维模型

这些功能会通过接口预留，作为后续迭代接入。

## 系统架构

系统分为六个模块：

1. `Telemetry`
   - 定义 `TelemetryFrame`
   - 定义 `ITelemetrySource`
   - 实现 `CsvTelemetrySource`
   - 负责 GBK CSV 读取、字段解析、坏行跳过和加载日志

2. `Playback`
   - 管理播放、暂停、倍速、跳帧和当前帧索引
   - 提供统一的当前帧事件，供模型、UI 和轨迹同步更新

3. `Mapping`
   - 将经纬度转换为 Unity 本地坐标
   - 将深度映射到 Unity Y 轴负方向
   - 将航向、纵摇、横摇转换为模型旋转
   - 负责轨迹自动缩放和采样

4. `Visualization`
   - 创建程序化滑翔机模型
   - 创建水下环境效果
   - 绘制实际轨迹、淡化未走轨迹、突出当前点
   - 实现相机系统

5. `UI`
   - 显示遥测仪表
   - 显示播放控制条
   - 显示目标信息、运行模式、报警状态
   - 提供相机切换和视觉效果开关

6. `Logging`
   - 记录 CSV 加载错误
   - 记录深度、电池、姿态等报警事件
   - 记录回放开始、暂停、跳转等事件

## CSV 字段映射

第一期固定支持当前 `2.csv` 的列结构，核心字段如下：

- `UTC时间`：原始时间标签，仅用于 UI 显示
- `经度(°)`：本地 X/Z 坐标计算
- `纬度(°)`：本地 X/Z 坐标计算
- `深度(m)`：Unity Y 轴负方向
- `高度(m)`：UI 显示，第一期不用于空间高度计算
- `航向(°)`：模型水平朝向
- `纵摇(°)`：模型 pitch
- `横摇(°)`：模型 roll
- `24V电压(V)`：仪表显示
- `24V电流(A)`：仪表显示
- `电池电量(%)`：仪表和低电量报警
- `工作模式`：状态显示
- `运行状态`：状态显示
- `目标航段`：当前任务段显示
- `目标航向(°)`：目标信息显示
- `目标深度(m)`：目标信息显示
- `目标高度(m)`：目标信息显示
- `主推进器转速(RPM)`：仪表显示
- `活塞位置(mm)`：仪表显示
- `转向角(°)`：仪表显示

已观察到的数据范围：

- 经度：约 `119.99990268` 到 `120.89792414`
- 纬度：约 `24.49967607` 到 `25.50028932`
- 深度：`0` 到 `1243.2 m`
- 航向：`0.1` 到 `360.0°`
- 纵摇：`-25` 到 `25°`
- 横摇：`-25` 到 `26°`
- 电池电量：`9%` 到 `96%`
- 工作模式：`水面模式`、`潜航`

## 坐标和时间策略

经纬度采用本地切平面近似：

- 第一条有效经纬度作为原点
- 纬度差换算为南北距离
- 经度差按原点纬度余弦修正后换算为东西距离
- 显示缩放默认自动适配轨迹范围，也允许后续在 Inspector 中调整

深度映射：

- `UnityY = -depth * depthScale`
- 默认 `depthScale` 约为 `1 / 20`，使 1243 m 深度显示为约 62 Unity 单位

时间策略：

- 播放顺序以 CSV 行顺序为准
- UI 显示原始 `UTC时间`
- 不依赖第一行异常时间值计算播放进度
- 默认根据目标帧率和倍速推进当前索引
- 拖动进度条时直接跳转到对应索引

## 场景与视觉

主场景打开后直接进入孪生回放界面。

三维场景包含：

- 简化滑翔机：机身、翼面、尾翼、头部方向标识
- 实际轨迹：亮青色 LineRenderer
- 已回放轨迹：更亮
- 未回放轨迹或完整轨迹参考：更淡
- 当前点标记：小型发光或高亮标记
- 海底平面或低复杂度地形
- 蓝绿色指数雾
- 悬浮粒子
- 简化体积光束

性能优先级高于写实效果。第一期视觉目标是有明确水下氛围、能支持展示，不追求昂贵的真实光追或复杂海浪。

## 相机与交互

相机模式：

- 跟随视角：默认，带阻尼跟随滑翔机
- 全局视角：观察完整轨迹和当前点
- 自由视角：鼠标右键旋转，滚轮缩放，键盘平移

回放交互：

- 播放
- 暂停
- 0.5x、1x、2x、5x、10x 倍速
- 进度条拖动跳转
- 相机模式切换
- 轨迹、粒子、雾效开关
- 显示当前 CSV 行号和回放进度

## 报警与日志

第一期报警规则：

- 深度超过阈值时报警，默认阈值可配置
- 电池低于阈值时报警，默认阈值可配置
- 纵摇或横摇绝对值过大时报警，默认阈值可配置
- CSV 解析失败行计入加载日志

日志输出：

- `Logs/load.log`
- `Logs/alarm.log`
- `Logs/playback.log`

日志目录放在应用可写路径下。Unity Editor 中可放在工程内运行时目录，Windows 打包后放在程序数据路径或应用旁的可写目录。
