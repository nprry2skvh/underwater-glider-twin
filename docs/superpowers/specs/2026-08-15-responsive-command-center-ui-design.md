# UnderwaterGliderTwin 响应式指挥台 UI 设计

## 目标

将运行时 UI 重构为“固定功能区 + 自适应中央 3D 视图区”的紧凑指挥台，解决当前界面中的三类问题：

- 顶部配置区过高，压缩中央 3D 视图；
- 左右信息面板内容密度不均，产生大面积无效留白；
- 绝对坐标、重复工具条和层级冲突导致控件遮挡。

本设计保持现有仿真、遥测、海流、预测、回放和相机控制功能不变，优先复用现有 UI Root、Prefab 和对象名称。

## 目标分辨率与布局模式

参考分辨率为 1920×1080，Canvas 使用 `Scale With Screen Size`，Match 为 0.5。

| 窗口尺寸 | 模式 | 布局规则 |
| --- | --- | --- |
| ≥1600px 宽 | 完整三栏 | 左栏 260–280px，右栏 300–320px，间距 16px |
| 1280–1599px 宽 | 压缩三栏 | 左栏 230–240px，右栏 260–280px，间距 12px |
| <1280px 或中央视图 <640px | 抽屉模式 | 隐藏左右栏，只保留边缘入口；同侧抽屉独占空间 |
| <1024×640 | 受限模式 | 不保证完整三栏，仅保证抽屉模式和中央视图可用 |

1024×640 不承诺完整三栏，以避免“最小中央视图宽度”和“两侧信息栏”互相挤压。若平台允许设置窗口最小尺寸，可将 1024×640 作为建议值；否则使用抽屉模式继续运行。

## 页面层级

```text
RuntimeCanvas
└── UiRoot
    ├── SystemBar
    ├── ConfigurationArea
    ├── MainBody
    │   ├── TelemetryColumn
    │   ├── ViewportColumn
    │   └── StatusColumn
    ├── PlaybackBar
    └── DrawerLayer
        ├── DrawerScrim
        ├── TelemetryDrawer
        ├── StatusDrawer
        └── ConfigurationDrawer
```

`MainBody` 使用 `HorizontalLayoutGroup`。`ViewportColumn` 设置 `flexibleWidth = 1` 和 `minWidth = 640`；左右栏使用 `LayoutElement` 设置 `minWidth` 与 `preferredWidth`。顶部配置区和底部播放区设置固定/最小高度，不让内容尺寸向外撑开。

根节点不使用 `ScrollRect`。滚动只出现在配置高级参数、左侧遥测内容和右侧状态内容内部，每个区域最多一个纵向 `ScrollRect`。`ContentSizeFitter` 仅允许用于滚动内容节点，避免与外层 `LayoutGroup` 形成尺寸循环和布局抖动。

## 区域规格

### SystemBar

高度 52–60px，只放产品名称、系统状态、海流任务状态、时间和窗口操作。参数和播放按钮不进入系统栏。

### ConfigurationArea

桌面大尺寸高度约 176px，压缩模式高度约 150–160px，最小高度 140px。内部固定为两行：

第一行保留 CSV 路径/加载、预测模型、预测时域、应用、停止预测。

第二行保留运行仿真和海流配置入口；循环次数、周期、深度、速度、航向、俯仰、横滚等低频参数进入“高级参数”折叠区或抽屉。

高级参数在内部 `ScrollRect` 中滚动，不能改变 `ConfigurationArea` 的外部高度。

### MainBody

中央 3D 区始终是视觉中心。视图工具条固定在 `ViewportColumn` 内部顶部，只保留跟随、全局、俯视、侧视、环绕、复位视角和海流图例，不覆盖配置区或播放区。

左侧由遥测卡片和姿态/导航卡片组成；右侧由状态摘要、任务进度、预测指标和工程校核组成。左右卡片内部滚动，不带动系统栏、中央视图或播放栏。

### PlaybackBar

高度约 88–100px，作为唯一播放控制面板，包含播放、倒放、回放、重置、导出、时间轴、速度、图层开关和退出。其他面板不重复放置播放或视图控制。

## 抽屉交互

- 小窗口时左右栏隐藏，边缘显示 36–40px 入口按钮。
- 抽屉最大宽度 320px；1920px 下不超过 360px。
- 同时只允许打开一个信息抽屉。
- 打开时显示约 20% 黑色遮罩，遮罩阻止中央 3D 视图点击。
- 按 `Escape`、点击遮罩或再次点击入口关闭。
- 关闭后键盘焦点返回原入口按钮。
- 动画只使用位移和透明度，默认约 160ms；关闭动画时直接切换最终状态。
- 关闭抽屉时设置 `interactable = false`、`blocksRaycasts = false`，避免透明对象拦截点击。

## 视觉系统

### 颜色角色

| 用途 | 颜色 |
| --- | --- |
| 页面背景 | `#071821` |
| 普通面板 | `#0B2430` |
| 浮层/抽屉 | `#102F3C` |
| 分隔线 | `#164454` |
| 普通边框 | `#2C6C7A` |
| 主文字 | `#E5F2F3` |
| 次要文字 | `#91B5BE` |
| 主强调色 | `#5DD7E8` |
| 成功状态 | `#41C6A7` |
| 警告状态 | `#F2C66D` |
| 错误状态 | `#F27B7B` |

面板只使用深色底。青色用于选中态、进度、关键边线和主操作；黄色只用于警告和预测历史；状态同时显示文字，不依靠颜色单独表达含义。

### 组件状态

普通按钮使用深蓝底 `#153B4A`，悬停使用 `#1E5264`，按下使用 `#5DD7E8`，禁用使用 `#28414A`。按键焦点增加 2px 浅色描边。主按钮使用 `#5DD7E8`，文字使用 `#071821`，不使用大面积发光或高饱和渐变。

### 字体与数值

系统标题 18px，区域标题 14–16px，标签 11–12px，普通数值 13px，关键 KPI 18–20px。数值列使用固定宽度，优先使用等宽数字或 Tabular Figures；单位始终显示，例如 `160 m`、`0.65 m/s` 和 `42°`。长路径、状态文字和错误信息使用省略号或换行，不得撑破父级布局。

## 交互可用性

- 所有输入框提供可见标签。
- 图标按钮提供 Tooltip 或文字说明。
- 所有按钮提供默认、悬停、按下、禁用和键盘焦点状态。
- 输入错误显示在对应字段旁边；提交失败时聚焦第一个错误字段。
- Tooltip、错误提示和状态更新不遮挡主要操作区。
- 滚动条只出现在内部内容区，避免嵌套滚动冲突。
- 键盘导航顺序遵循系统栏 → 配置区 → 主体区域 → 播放区；抽屉打开时焦点限制在抽屉内。

## 验收标准

### 布局

- 1920×1080 显示完整三栏，中央 3D 区是最大视觉区域。
- 1366×768 左右栏压缩后不遮挡中央视图、顶部栏和播放栏。
- 1280×720 可稳定进入压缩三栏或抽屉模式。
- 1024×640 使用抽屉模式，不承诺完整三栏。
- 配置区、左右内容区和抽屉各自滚动，不产生嵌套滚动冲突。

### 交互

- 播放、视角和图层控制各只有一组入口。
- 抽屉打开时遮罩、焦点、Escape 关闭和焦点回退均正常。
- 所有输入框、按钮和状态信息可读，长文本不会撑破布局。
- 控件不存在透明对象拦截点击的问题。

### 功能

- CSV 加载、参数应用、运行仿真、海流配置、预测、回放和相机控制保持原有行为。
- EditMode 测试保持通过。
- 至少生成 1920×1080、1366×768、1280×720 和 1024×640 四组运行截图进行视觉检查。

## 非目标

- 不重写仿真、海流采样、预测模型或回放业务逻辑。
- 不引入新的 UI 框架。
- 不把所有参数永久隐藏到抽屉中；高频操作必须保持可见。
- 不以装饰性发光、渐变或大面积高饱和颜色代替信息层级。
